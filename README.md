## 🗃️ Projects

### 📱 [PHONE-FLEET](https://github.com/devdutt-dave007/PHONE-FLEET)

An ongoing experiment around **reusing old Android phones as a managed device fleet**.

The project started from a simple question:

> *What can I actually do with a bunch of old phones instead of letting them sit unused?*

I've been working with **ADB, Bash, SSH, device monitoring and automation** to control and manage the devices.

The project is currently on a break while I explore other areas, but I plan to return to it.

The monitoring side of PHONE-FLEET — experimenting with collecting device information and keeping track of things like **battery, temperature and memory usage**, with automated alerts.
